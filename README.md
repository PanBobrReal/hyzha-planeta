# Хижа Планета — онлайн

Без залежностей: лише Node.js 18+. Кімнати зберігаються в пам'яті сервера.

## Локально
    npm start      # http://localhost:3000

## Щоб грали друзі (будь-який хостинг з Node.js)
1. Завантажте цю папку на GitHub.
2. На render.com (або railway.app / fly.io): New → Web Service → оберіть репозиторій.
   Build command: (порожньо) · Start command: `npm start`. Порт береться зі змінної PORT автоматично.
3. Відкрийте виданий URL, введіть ім'я, натисніть «Створити кімнату», надішліть друзям посилання виду `https://ваш-сайт/?room=ABCD`.
4. Хост обирає, хто Істота (або випадково), і натискає «Почати гру».

Примітка: на безкоштовних тарифах сервер «засинає», а перезапуск стирає активні кімнати.

## Налаштування, які треба звірити з коробкою (початок server.js, об'єкт CFG)
- GOAL — довжина треку до «Перемоги» (в інструкції не вказана);
- ARTEMIA_SPACES — поділки треку Порятунку із символом Артемії;
- HUNT_LIMIT — карт Полювання за хід;
- у HUNT та SURV є лише 4 + 4 карти, описані в PDF; додайте решту з коробки за тим самим шаблоном.

## Тест
Запустіть `npm start`, потім `node tests/bots.js 4 20` — ігри ботів на 4 гравців.
